### **Engineering**

* **Full-Stack Next.js Architecture:** Built with the Next.js App Router, React Server Components (RSC), and Server Actions for optimal SSR/SSG rendering performance.
* **Backend & API Systems:** Designing type-safe REST APIs with Node.js, Route Handlers, Zod schemas, and middleware validation layer integrations.
* **Database Design & ORM:** Schema modeling, migrations, indexing, and transactional operations using PostgreSQL and Prisma ORM.
* **Auth & Security:** Implementing session handling, OAuth flow integrations, role-based access control (RBAC), and server-side authorization checks.
* **State & Performance:** Application state optimization with Zustand/TanStack Query, route caching, revalidation strategies, and optimistic UI updates.
* **Payments & Media:** End-to-end payment gateway integrations (Razorpay) alongside media uploads, CDN delivery, and cloud storage management.
